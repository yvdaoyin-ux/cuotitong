# 错题通

> **参赛作品全名（用于报告封面 / 申报书 / 答辩 PPT）**
> **错题通——基于贝叶斯估计与遗忘曲线的薄弱点诊断与智能组卷系统**

错题本 + 薄弱点诊断 + 智能组卷。纯前端、本地优先、无账号、无服务器。

面向数学类课程：数学分析、高等代数、概率论与数理统计、高等数学。

## 它解决什么

学生做错题后通常只做「抄下来」，既记不住，也不知道该先补哪一章。
常见错题 App 把题存起来就算完，不做诊断，而且需要注册联网。

这个工具做三件市面上少做的事：

1. **贝叶斯平滑掌握度** —— 不直接用「对/总」算正确率（答对 1 题就是 100%，
   答错 1 题就是 0%，这种估计毫无统计意义），而是用 Beta 后验均值，
   并给出 **95% 可信区间**。样本不足时界面直接显示「数据不足」。
2. **遗忘曲线** —— 用 `R = exp(−t/S)` 估算记忆留存，按
   `优先级 = (1−R)×(1−掌握度)` 决定复习顺序，答对拉长间隔、答错缩短。
3. **加权无放回组卷** —— 按薄弱度加权抽题，同一知识点不超过总题数的 40%，
   避免一张卷子全考同一章。

## 怎么用

**在线**：打开发布地址即可。

**离线**：把 `index.html` 连同 `css/`、`js/`、`lib/` 一起放在同一目录，
用浏览器打开 `index.html`。`file://` 协议下功能完整（这也是为什么本工程
**刻意不用 ES6 module** —— 浏览器会以 CORS 为由拒绝加载）。

第一次进来是空库。想看效果：首页点「先载入示例数据看看」，
或到设置页载入，试完可一键清除。示例题带「示例」角标，**不会被导出**。

## 技术约束与选择

| 决策 | 理由 |
|---|---|
| 原生 JS + 经典脚本（非 ES module） | `file://` 下浏览器拒绝加载 module，会破坏离线兜底 |
| `localStorage` 单 key 存整库 | 数据量级是「一个学生一学期的错题」，无需 IndexedDB |
| **只存作答事件，掌握度实时派生** | 双写必然不一致；删题后无法回滚 |
| KaTeX / ECharts 放本地 `lib/` | 不依赖 CDN；ECharts 在诊断页按需加载 |
| 无后端、无账号 | 数据是学生隐私；也省掉运维成本 |

## 目录

```
index.html           单页入口
css/app.css          样式（含 @media print）
js/stats.js          三个统计模型（纯函数，可直接 Node 测试）
js/storage.js        localStorage + 数据模型 + 版本迁移
js/ui-*.js           各页面
js/sample-data.js    示例数据（带历史作答，能驱动完整演示）
js/export-usage.js   匿名使用数据导出（白名单，不含任何题干/答案）
lib/                 KaTeX + ECharts + 字体
tests/               114 项单元测试
build/make-dist.js   打包：单文件 html + 离线 zip
docs/                算法说明 / 系统设计 / 用户手册 / 测试报告 / 分发说明
```

## 测试

不依赖任何测试框架，只用 `node:assert`，无需 `npm install`：

```bash
node tests/stats.test.js     # 45 项：Beta 分位数、掌握度、遗忘曲线、组卷、复习队列
node tests/storage.test.js   # 22 项：CRUD、备份、v1→v2 迁移
node tests/export.test.js    # 29 项：匿名导出（含 8 项隐私专项）
node tests/render.test.js    # 18 项：公式渲染与转义顺序
```

全部通过输出「通过 N 项，失败 0 项」。

## 打包

```bash
node build/make-dist.js
```

生成 `dist/错题通-单文件.html`（约 1.8 MB，全部内联，双击即用）与
`dist/错题通-离线版.zip`（约 720 KB）。

## 隐私

- 数据只存在用户自己的浏览器里，不上传任何服务器
- 「导出使用数据」采用**白名单**：只导出计数与时间，**绝不含**题干、
  答案、解析、用户手写解法、自建知识点名称
- 示例数据在导出时被强制排除，避免演示数据混进真实统计

## 已知局限

- 「答对/答错」由用户自评，存在高估风险（纯前端无法机器判分）
- 遗忘曲线的稳定度递推（×2 / ×0.5）是启发式参数，非拟合所得
- 掌握度是知识点粒度，未区分同一知识点内的题目难度
- 未做多标签页并发写入保护（单人使用风险低）
