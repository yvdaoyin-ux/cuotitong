## 三、Unicode 符号实测表（你要我贴进汇报的）

用 KaTeX 0.16.9、`throwOnError:true` + `strict:'ignore'`，实测 75 个常见符号：

| 类别 | 符号 | 结论 |
|---|---|---|
| 运算符 | × ÷ · − ± ∓ | **全部可直接渲染** |
| 关系 | ≤ ≥ ≠ ≈ ≡ ∼ ∝ | **全部可直接渲染** |
| 集合 | ∈ ∉ ⊂ ⊆ ∪ ∩ ∅ ∖ | **全部可直接渲染** |
| 逻辑 | ∀ ∃ ¬ ∧ ∨ | **全部可直接渲染** |
| 箭头 | → ← ↔ ⇒ ⇔ | **全部可直接渲染** |
| 特殊 | ∞ ∂ ∇ ∑ ∏ ∫ ∬ √ | **全部可直接渲染** |
| 希腊 | α β γ δ ε θ λ μ π ρ σ τ φ ω ξ Δ Σ Ω Φ Ψ Γ Λ Π | **全部可直接渲染** |
| 数集 | ℝ ℂ ℕ ℤ ℚ | **全部可直接渲染** |
| 其它 | ⋯ … ° ′ ⟨ ⟩ ∴ ∵ | **全部可直接渲染** |

**单个符号 75/75、真实语境 25/25 全部通过。**

**结论：规则 6（Unicode 符号 → LaTeX 命令转换）可以整体省略。** 你的任务书建议做这个转换，我实测后发现 KaTeX 已经原生支持，多写一层转换反而引入风险。

**真正必须处理的是全角字符**：`（` `）` `，` `＝` `＄` 等。它们虽"能渲染"，但实测产出是**乱码**（如 `（x）` 的可见文字会重复三遍），必须归一为半角。这一项 `normalizeMath` 已实现并有测试。

复现：`node tools/unicode-compat.js`
