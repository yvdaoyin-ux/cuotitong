## 三、Unicode 符号实测表（已按你的更正 a 重测）

用 KaTeX 0.16.9、`throwOnError:true` + **strict 回调收集警告**（不再是 `'ignore'`），实测 75 个常见符号：

| 类别 | 符号 | 结论 |
|---|---|---|
| 运算符 | × ÷ · − ± ∓ | 无警告 |
| 关系 | ≤ ≥ ≠ ≈ ≡ ∼ ∝ | 无警告 |
| 集合 | ∈ ∉ ⊂ ⊆ ∪ ∩ ∖ | 无警告（**∅ 有 unknownSymbol 警告**） |
| 逻辑 | ∀ ∃ ¬ ∧ ∨ | 无警告 |
| 箭头 | → ← ↔ ⇒ ⇔ | 无警告 |
| 特殊 | ∞ ∂ ∇ ∑ ∏ ∫ ∬ | 无警告（**√ 有 unknownSymbol 警告 + 无根号横线，见下）** |
| 希腊 | α β γ δ ε θ λ μ π ρ σ τ φ ω ξ Δ Σ Ω Φ Ψ Γ Λ Π | 无警告 |
| 数集 | ℝ ℂ ℕ ℤ ℚ | 无警告 |
| 其它 | ⋯ … ° ⟨ ⟩ ∴ ∵ | 无警告（**′ 有 unknownSymbol 警告**） |

**结果：72 个无警告，3 个（∅、√、′）有 unknownSymbol 警告但渲染视觉与 `\emptyset`、`\surd`、`\prime` 一致。**

**你（Claude）的更正 b 我已复验属实**：`√x` 渲染出来只有「根号符号 + x」、**没有根号横线**，与 `\sqrt{x}` 语义不同。因此 normalizeMath 已加一条机械规则：

```
√{…} → \sqrt{…}
√(…) → \sqrt{…}（圆括号改花括号）
√x / √2 → \sqrt{x} / \sqrt{2}（单个字母/数字）
其它（末尾、后接空格、已是 \sqrt）→ 不动
```

已补 8 项测试（`tests/mathtext.test.js` C2 组）。

**结论修正：规则 6 对 72 个符号整体省略；∅、√、′ 不转换（渲染一致）；√ 单独做机械转换。**

**全角字符（更正 c 已采纳）**：`（` `）` `，` `＝` `＄` 等触发 `unicodeTextInMathMode` 警告，按文本字体渲染，**间距和斜体与数学字体不一致**（不是我之前说的"乱码"），必须归一为半角。这一项 `normalizeMath` 已实现并有测试，文档措辞已改。
