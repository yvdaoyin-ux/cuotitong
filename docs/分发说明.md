## 一、发什么

三种方式，按场合选：

| 方式 | 适合 | 对方怎么用 |
|---|---|---|
| **发在线链接** | **首选** | 直接点开，手机浏览器即可 |
| 发 `错题通-单文件.html`（1.8 MB） | 对方网络不好、或想离线用 | 下载后选「用浏览器打开」 |
| 发 `错题通-离线版.zip`（722 KB） | 想存着长期用 | 解压后打开 `index.html` |

**建议先发链接**，微信里点链接的体验最顺。对方说打不开或想要离线的，再发文件。

> ⚠️ 微信里点开链接可能提示「用浏览器打开」，选它即可。
> 微信内置浏览器对 html 文件限制较多，离线包尤其要用系统浏览器。

## 二、发之前先自己过一遍

**必须做**，否则发出去可能是个坏版本：

1. 打开 <https://yvdaoyin-ux.github.io/cuotitong/>
2. 首页应显示「还没有记录过错题」+ 一个 **「📥 先载入示例数据看看（12 道）」** 按钮
3. 点它 → 应跳到诊断页（图表可能要先等几秒），**三张图都画出来**
4. 点底部「组卷」→ 生成一份练习 → 随便自评几题 → 交卷 → 看到「本次结果」
5. 回设置页，点「清除示例数据」→ 回到空库

**五步全过**才算可以发。

## 四、对方可能问到的问题（你先知道怎么答）

| 对方问 | 你答 |
|---|---|
| 打不开 / 一片空白 | 换个浏览器试试（Chrome / Edge / Safari）；微信里点右上角「⋯」→「在浏览器打开」 |
| 图标半天不出来 | 第一次要下载 1 MB 图表库，等几秒；之后就快了 |
| 要不要注册 | 不用。没有账号、没有服务器 |
| 我的数据你看得到吗 | 看不到。全在你自己浏览器里 |
| 换手机怎么办 | 旧手机「设置」→「导出备份」，新手机「从备份恢复」 |
| 为什么显示「数据不足」 | 那个知识点你做过的题还不到 5 道，样本太少给结论不靠谱。多做几道就有了 |
| 能传图片吗 | 这版不能，只支持文字 + LaTeX 公式 |
| 能自动判对错吗 | 不能，要自己点「做对了/做错了」。数学过程没法机器判 |
| 会不会哪天突然收费 | 不会，纯静态页面，没有账号也就没有收费的地方 |

## 五、发出去之后

1. **记录谁在试用**：几个人、什么专业、用的哪套教材，方便你写报告里的「应用情况」。
2. **一周后收反馈**：重点问「哪一步最麻烦」，不要问「好不好用」。
3. **收匿名数据**：让对方在设置页点「导出使用数据（JSON）」发你。
   - 里面**只有**科目、错因、题数、对错数、时间（精确到分钟）
   - **没有**题干、答案、手写解法、自建知识点名称
   - 详见 `docs/算法说明.md` 与 `tests/export.test.js` 的隐私测试
4. **报告里要如实区分**：示例数据和你的测试数据**不能**算作「真实使用数据」。

## 七、更新线上版本 / 重新打包

**改了代码要上线**：

```bash
cd "C:/Users/fa'r/Desktop/挑战杯/03-错题通"
node build/make-dist.js          # 重新生成 dist/ 两个交付物
git add -A
git commit -m "说明这次改了什么"
git push origin main             # 推送后 GitHub Pages 约 1 分钟自动更新
```

> ⚠️ `dist/` 在 `.gitignore` 里，不会推上 GitHub（线上用源码目录直接跑）。
> 但**发给同学的离線包是 `dist/` 里的**，所以改完代码一定要重新打包，
> 否则发出去的文件还是旧版。

如果想加问卷链接：编辑 `js/config.js` 里的 `FEEDBACK_URL`，commit + push，再重新打包。
