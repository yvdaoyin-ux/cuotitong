# 分发说明（给同学看的）

> 这份文件是写给**你**的：告诉你怎么把「错题通」发出去、对方怎么打开、可能遇到什么问题。
> 最后一节可以直接复制粘贴给同学。

---

## 一、发什么

`03-错题通/dist/` 下有两个文件，任选其一：

| 文件 | 大小 | 适合 | 对方怎么用 |
|---|---|---|---|
| **错题通-单文件.html** | 1.8 MB | **首选**。发微信最省事 | 收到后点开，选「用浏览器打开」 |
| 错题通-离线版.zip | 722 KB | 网络差、或对方想存着慢慢用 | 解压后打开里面的 `index.html` |

**建议两个都发**，让对方自己挑。zip 更小，但需要解压；单文件点开就能用。

---

## 二、发之前先自己过一遍

**必须做**，否则发出去可能是个坏版本：

1. 双击 `dist/错题通-单文件.html`，用浏览器打开
2. 首页应显示「还没有记录过错题」+ 一个 **「📥 先载入示例数据看看（12 道）」** 按钮
3. 点它 → 应跳到诊断页，看到雷达图、错因饼图、科目柱状图**三张图都画出来**
4. 点底部「组卷」→ 生成一份练习 → 随便自评几题 → 交卷 → 看到「本次结果」
5. 回设置页，点「清除示例数据」→ 回到空库

**五步全过**才算可以发。

---

## 三、怎么发（微信）

1. 微信 → 找个「文件传输助手」→ 把 html 发给自己
2. 确认能收到、能打开
3. 再转发给同学

> ⚠️ **微信直接点开 html 会受限**，正常现象。让同学点右上角「⋯」→「在浏览器打开」。
> 这一句务必在发给对方时一起说，否则对方会以为文件坏了。


## 五、对方可能问到的问题（你先知道怎么答）

| 对方问 | 你答 |
|---|---|
| 打不开 / 一片空白 | 是不是在微信里直接点的？右上角「⋯」→「在浏览器打开」 |
| 要不要注册 | 不用。没有账号、没有服务器 |
| 我的数据你看得到吗 | 看不到。全在你自己浏览器里 |
| 换手机怎么办 | 旧手机「设置」→「导出备份」，新手机「从备份恢复」 |
| 为什么显示「数据不足」 | 那个知识点你做过的题还不到 5 道，样本太少给结论不靠谱。多做几道就有了 |
| 能传图片吗 | 这版不能，只支持文字 + LaTeX 公式 |
| 能自动判对错吗 | 不能，要自己点「做对了/做错了」。数学过程没法机器判 |
| 会不会哪天突然收费 | 不会，纯静态页面，没有账号也就没有收费的地方 |

## 六、发出去之后

1. **记录谁在试用**：几个人、什么专业、用的哪套教材，方便你写报告里的「应用情况」。
2. **一周后收反馈**：重点问「哪一步最麻烦」，不要问「好不好用」。
3. **收匿名数据**：让对方在设置页点「导出使用数据（JSON）」发你。
   - 里面**只有**科目、错因、题数、对错数、时间（精确到分钟）
   - **没有**题干、答案、手写解法、自建知识点名称
   - 详见 `docs/算法说明.md` 与 `tests/export.test.js` 的隐私测试
4. **报告里要如实区分**：示例数据和你的测试数据**不能**算作「真实使用数据」。
