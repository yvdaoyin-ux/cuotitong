# 错题通 —— 研究报告（骨架）

> 依据参赛通知：科技发明制作 B 类必须附研究报告，含**图表、曲线、试验数据、原理结构图、外观图（照片）**。
> 格式硬规（申报书说明第 5 条）：**四号楷体、A4 纸、版面尺寸 14.5×22cm**。
> 使用方式：每节列了「可引用的图表编号」和「仓库中的现有事实」；【待用户数据】处不得编造。
> 图表文件全部在 `docs/report-figures/`，索引见 `docs/report-figures/index.md`。

## 一、作品的目的与意义

**要点（全部可写）**：
- 错题学习法的真实痛点：整理耗时（抄题/画图/排版）、复习凭感觉（不知道该复习哪道）、重复做已掌握的题浪费时间；
- 传统纸质错题本无法量化"掌握到什么程度"，也无法给出"今天该复习哪几道"的客观答案；
- 目的：把错题整理的最小成本压到"拍张照/抄个来源"，把复习决策交给可解释的统计模型。

**可引用**：F1（系统结构图）。
**慎写**：不要写"解决效率低下问题"这类无来源的量化断言；耗时对比等 F10 数据到位后才能写。

## 二、制作过程（建议时间线叙述，事实全部来自仓库）

- 需求与选型：纯前端单文件（微信分发、离线可用）→ 放弃 ES6 module（file:// CORS 会毁掉离线 zip）【阶段 1 汇报有记录】；
- 数据与模型：事件溯源（掌握度不落盘，由 answers 事件流实时计算）→ schema v3（source/entryMode/imageIds）；
- 录入效率专项：94 符号公式工具栏（insertAt 纯函数）、拍照存图管线（长边 1280 压缩 ≤200KB、IndexedDB Blob）、基准脚本对比（手打 278 键 vs 工具栏 24 点击+69 字符）；
- 识别专项：glm-ocr 探针实测（CORS/格式/耗时/tokens）→ Go 判据 → 最小集成（口令解锁、每日限额、降级设计）；
- 质量保障：自动化测试 318 项（统计模型/迁移/隐私/图片/OCR 解析/图标契约）；无头浏览器端到端验收。

**可引用**：F6（按键基准）、F9（测试汇总表）、F1（结构图）。
**注意**：过程叙述里的"踩坑"（esc() 先于渲染、openKeyCursor 语义等）可挑 2-3 个写，体现工程真实性。

## 三、结果（已实现功能与验证）

- 功能清单：四科 71 知识点库；极速/完整双模式录题；薄弱点诊断（掌握度排行+95% 可信区间）；加权组卷（单点 ≤40%、不足逐级放宽）；今日复习；打印成卷；匿名数据导出；备份恢复；可选识别。
- **可引用**：F2/F3（模型性质：遗忘曲线、Beta 后验收敛——**必须写"模型性质演示"**）、F4/F5（确定性脚本验证：占比上限、权重-抽中频次）、F7（识别实测：5/5 印刷体可用、中位 982ms——**待用户提供 CER 后补客观错误率**）、F8（界面外观图 7 张）、F9（318 项测试）。
- 【待用户数据】试用人数、使用时长、录入耗时对比（F10）——回收后补入，此节才能写"实际应用情况"。

## 四、创新点

1. **贝叶斯平滑掌握度**：Beta-二项共轭 + 均匀先验，样本 <5 明确"数据不足"，避免 0%/100% 极端值（F3）；
2. **可解释的复习调度**：R=e^(−t/S) 与薄弱度联合定优先级，公式公开、参数含义可讲清（F2）；
3. **面向小样本的工程化**：纯前端离线、单文件分发、零部署成本；识别失败不影响录题的降级设计；
4. **隐私边界明确**：匿名导出白名单制（识别原文实测出不去）。

**不要写**："国内领先""独创"等无法证实的断言；与具体商业产品对比。

## 五、实际应用情况或应用前景

- 已实现：线上部署（GitHub Pages）+ 离线单文件两种分发方式；
- 【待用户数据】试用范围与反馈（B3 第 5 栏同一来源）；
- 前景：班级内链接/文件传播；知识点库可扩展至其他理科课程；无服务器→零维护成本。

## 六、存在不足及下一步工作

**不足（如实）**：
1. 模型参数（遗忘曲线稳定度 S 的对错倍率等）为启发式设定，未用真实数据拟合；
2. 多机型真机兼容性测试未全面完成（Android Chrome / iOS Safari / 微信内置）；
3. 识别依赖第三方在线接口，离线时不可用（应用有降级设计）；
4. 知识点需要用户自己选择，暂无自动建议（有意为之，避免错误标签污染统计）。

**下一步**：
1. 用试用数据拟合与校准模型参数；
2. 补齐真机兼容性测试并修复发现的问题；
3. 评估"识别结果自动建议知识点"的可行性与风险；
4. 申请软件著作权。
