## 三、本次踩到的坑（已写进 PROJECT_STATE/CURRENT）

1. **A4 的顺序坑**：先 auto-`$` 包裹再补空格的话，模板尾已变成 `$`，`/\\[A-Za-z]+$/` **永远匹配不上**——空格必须落在 `$` 之内（`$\cdot $`）。自写测试当场抓住，改为「先补空格、再包 `$`」。
2. **scrollIntoView('nearest') 不感知 fixed 遮挡**：题干部分可见时原生滚动不动作，底边仍被工具栏盖住 17px——padding 方案 + 显式 scrollBy 校正才真正解决。
3. **跟滚校正的副作用**：把校正挂在 visualViewport 的 scroll 事件里，用户聚焦题干后**想滚动看别处会被强行拉回**（自己截图时撞见）。已改为只在聚焦瞬间与键盘尺寸变化（resize）时校正，用户滚动不干预。
4. **grid/flex 子项默认 min-width:auto**：工具栏第一行的 tabs 容器不收缩，把 `⏭`/`↶` 挤出 375px 视口——`min-width:0` 显式放开。
5. **A4 的已知代价**：`\mu `/`\sigma ` 尾空格使题 4 从「逐字一致」变「渲染等价」（KaTeX 渲染逐字节相同）——如实写进录入效率说明，未掩饰。
6. **v1.2 的 commit message 把未写的 B/C 文档提前列了进去**（当时 B/C 尚未创建）——文件清单以 `git show --stat` 为准，下不为例。
