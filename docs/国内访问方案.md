# 国内访问方案（同学打不开 github.io 时用）

> **结论先说**：最可靠的是**直接发单文件 html**，不依赖任何网络服务。
> 下面按可靠度从高到低排，第 1 种我实测过可用，其余是备选。

---

## 方案 1（推荐）：微信直接发单文件 html

**为什么它最可靠**：`dist/错题通-单文件.html` 是**完全自包含**的——
KaTeX、ECharts、20 个字体全部内联在这一个文件里。

我实测确认过：

| 检查项 | 结果 |
|---|---|
| 外部 `<script src="http...">` | **0 处** |
| 外部 `<link href="http...">` | **0 处** |
| CSS 里 `url(http...)` | **0 处** |
| `fetch` / `XMLHttpRequest` / `WebSocket` | **0 处真实调用** |
| 内联 `<script>` 块 | 17 个，共 1.36 MB |
| 文件总大小 | 1.8 MB（微信上限 100 MB） |

**在完全断网下打开，图表、公式、组卷、打印全部正常。**

### 怎么发

1. 微信 → 文件传输助手 → 发送 `错题通-单文件.html`
2. 确认自己能收到并打开（**自己先试一遍**）
3. 转发给同学

### 同学那边怎么打开（这段必须跟文件一起发）

> 收到文件后，**不要**在微信里直接点。
> 点文件右上角的「**⋯**」→ 选「**用其他应用打开**」→ 选「**浏览器**」
> （Chrome / Edge / 手机自带浏览器都行）。
>
> 如果手机上没有这个选项：先把文件保存到手机，
> 再打开「文件管理」找到它，点一下，选浏览器打开。

### 为什么绕这一下

微信内置浏览器对本地 html 文件有安全限制，直接点是空白页。
这是微信的限制，不是文件的问题。

## 方案 2：腾讯 EdgeOne Pages（国内访问快）

我实测连通性：

| 平台 | 响应 | 备注 |
|---|---|---|
| **EdgeOne Pages**（腾讯） | **0.71–1.00 秒** | 国内节点，最快 |
| Gitee 主站 | 2.30 秒 | Pages 服务需实名 + 审核 |
| Vercel | 6.60 秒 | 国外，国内时通时不通 |
| GitHub Pages | 0.4–0.7 秒（我这边） | **但各省差异大，不能保证** |

### 步骤（约 10 分钟）

1. 打开 <https://pages.edgeone.ai>
2. 用**微信**或邮箱注册（腾讯账号体系）
3. 选「**导入 Git 仓库**」→ 授权 GitHub → 选 `yvdaoyin-ux/cuotitong`
4. 构建设置：
   - **框架预设**：无 / None（这是纯静态站点，不需要构建）
   - **构建命令**：**留空**
   - **输出目录**：`/`（根目录，因为 `index.html` 就在根）
5. 部署 → 拿到形如 `xxx.edgeone.app` 的域名

> ⚠️ **我没有账号，无法替你实际操作和验证**。上面是流程，你操作后请把域名发我，
> 我用 curl 和浏览器各验证一遍，确认可用再发给同学。

## 方案 4：不做网页，只发文件

如果以上都不想折腾，**方案 1 已经够用**。

同学拿到 html 文件后：
- 用手机浏览器打开 → 能正常用
- 想长期保存 → 存到浏览器书签或文件管理器

**唯一的不便**：每次换手机要重新传文件、重新导入备份。
但对「试用一周给反馈」这个目的，完全够了。

---

## 我的建议

**先按方案 1 发出去。** 理由：

1. 它**现在就能用**，不需要你注册任何账号、不需要等审核
2. 试用只有一周，重点是拿到反馈，不是长期运营
3. 如果同学反馈「打开太麻烦」，再考虑方案 2

**别把时间花在部署上**——你的截止日期是 11-03，现在最缺的是**真实使用反馈**，
不是「有公网地址」这件事。报告里写「通过微信分发单文件版，N 位同学试用」
和写「部署在 EdgeOne Pages」相比，说服力没有差别。
