## 10. C 表：当前国内外同类课题研究水平概述（限 1000 字）

> 新写（任务书 3.5 授权）；只引用允许清单文献；不提及任何商业产品；不宣称优于任何模型。

**定稿**

```
（1）知识追踪。Corbett与Anderson于1994年提出贝叶斯知识追踪（BKT），把知识点的掌握状态建模为隐含状态，用逐次作答在线更新；其参数通常需要较多作答数据才能稳定估计。Piech等（2015）用循环神经网络做深度知识追踪，预测精度更高，但依赖大规模作答日志且可解释性较弱。两者均面向有成规模作答记录的教学场景。
（2）间隔重复与遗忘模型。Ebbinghaus（1885）的实验给出记忆保持随时间衰减的基本曲线。工程化方向上，SM-2等按回忆质量调整间隔的固定规则（Wozniak与Gorzelanczyk，1994）应用广泛；Pavlik与Anderson（2008）依据练习历史与遗忘强度联合计算最优练习安排；Settles与Meeder（2016）提出半衰期回归，用历史数据为每条内容拟合记忆半衰期；Tabibian等（2019）把间隔重复建模为随机过程并做全局优化。这些方法依赖对大量用户与内容的持续数据采集。
（3）测试效应。Roediger与Karpicke（2006）的实验表明，主动回忆比重复阅读更能提升长期保持，这支持“以练代看”的复习组织方式。
（4）本作品的定位。面向个人与小样本场景：用Beta-二项共轭更新估计掌握度并给出95%可信区间（方法参考Gelman等，2013），样本不足时明确提示“数据不足”而非给出极端值；复习优先级由指数遗忘曲线与薄弱度联合决定，组卷利用测试效应。模型简单、参数可解释、纯前端离线运行、零部署成本。本作品不宣称在预测精度上优于上述任何模型，其差异在于适用场景（个人小样本）与透明度。
```
