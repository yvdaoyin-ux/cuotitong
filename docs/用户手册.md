# 用户手册

> 适用：手机浏览器（微信内置浏览器、Safari、Chrome 均可）、电脑浏览器。
> 无需注册，无需联网（用离线包时），数据只存在你自己的设备上。

---

## 一、第一次打开

打开方式有两种，任选其一：

| 方式 | 做法 | 适用 |
|---|---|---|
| **在线** | 点开我发的网址 | 有网络、想随时用最新版 |
| **离线** | 把 zip 解压到手机，用浏览器打开里面的 `index.html` | 网络不稳定；或想彻底离线 |

> ⚠️ 微信里点开链接可能提示「用浏览器打开」，选**在浏览器中打开**即可正常使用。
> 微信内置浏览器对本地文件的限制较多，离线包建议用系统浏览器打开。

**第一次进来是空的**，这是正常的 —— 数据只属于你自己，不会从别人的账号「同步」过来。

## 二、录第一道错题

底部有五个标签，点 **✏️ 录错题**。

### 2.1 填什么

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 科目 | 必填 | 数学分析 / 高等代数 / 概率论与数理统计 / 高等数学 |
| 知识点 | **至少选一个** | 可以多选。一道题同时考两章时都勾上，诊断会更准 |
| 题干 | **必填** | 文字即可。**公式用 `$...$` 包起来** |
| 我的答案 | 可空 | 当初写错的答案，方便日后对比 |
| 正确答案 / 解析 | 可空 | 建议至少写思路，复习时很有用 |
| 错因 | 可空 | 五选一：概念不清 / 计算失误 / 公式记错 / 审题错误 / 思路不会 |

### 2.2 公式怎么写

用 LaTeX，两边加 `$`：

| 你想写 | 输入 |
|---|---|
| $\int_0^1 x^2\,dx$ | `$\int_0^1 x^2\,dx$` |
| $\lim_{n\to\infty} x_n$ | `$\lim_{n\to\infty} x_n$` |
| $\sum_{n=1}^{\infty}\frac{1}{n^2}$ | `$\sum_{n=1}^{\infty}\frac{1}{n^2}$` |
| 独立成行的公式 | 用两个美元符：`$$\frac{a}{b}$$` |

写错了也不会崩，会原样显示成源码，改回来即可。

### 2.3 找不到对应知识点怎么办

列表最下方有「新增知识点」输入框，写完点**添加**，它会被加进当前科目并自动选中。
自建的知识点和预置的用起来完全一样。

### 2.4 保存之后

会自动跳到 **📚 错题本**，并提示「已存入错题本」。

> 💡 **录题本身就算一次答错。** 这是有意的设计：你把题记进错题本，说明你做错了它，
> 这是一次真实的失败记录，要计入掌握度。否则你录了十道错题、一次没复习，
> 诊断页只会说「数据不足」，完全不符合实际情况。

### 2.5 录错了想改 / 想删

- **改**：在错题本里点那道题的「编辑」。
- **删**：进入编辑页，最下方有红色「删除这道题」。
  删除会**一并删掉这道题产生的所有作答记录**，相关知识点的掌握度会自动重算 ——
  所以误录的题不会永久拉低你的诊断结果。

## 三、看诊断

点 **📊 诊断**。

### 3.1 先看文字结论

最上面那一段是自动生成的，例如：

> 你在【微分中值定理及其应用】上掌握度最低，约 33%（95% 可信区间 13%–58%）。
> 这个知识点上的主要错因是【概念不清】。其次是【数项级数】（约 25%），建议先攻这两个。

### 3.2 再看图

| 图 | 看什么 |
|---|---|
| 掌握度雷达图 | 形状越往里缩，说明短板越多。至少 3 个知识点各有 5 次作答才会出现 |
| 错因分布饼图 | 你失分的主要模式：是算错、记错公式，还是根本不会 |
| 各科目平均掌握度 | 哪一科最该补 |

### 3.3 「数据不足」是什么意思

比如显示「数据不足（2/5）」：

- 意思是这个知识点你只作答了 2 次，**低于 5 次的门槛**
- 统计上，两三次作答的结论完全可能是运气
- 继续做题，到 5 次就会给出正式结论和可信区间

**不要因为显示「数据不足」就觉得工具坏了** —— 恰恰相反，它在诚实地告诉你
「现在还看不出来」。

### 3.4 括号里的数字是什么

像 `44% 16–76%` 这样的，44% 是当前估计，16%–76% 是 95% 可信区间。
区间越窄说明估计越可靠。**区间很宽时，别把那个百分比太当真。**

## 四、组卷练习

点 **🎯 组卷**，选科目和题数，点「生成一份练习」。

### 4.1 题目是怎么挑的

按两个因素加权：

1. **你忘得多厉害**（越久没碰、越常答错的越靠前）
2. **你掌握得多差**（掌握度低的更优先）

同时限制：**同一个知识点最多占四成题量**，避免一整张卷子都在考同一章。

### 4.2 题数为什么可能少于你选的

比如选了 10 道，但该科目下只有 4 道错题，那只能出 4 道。
页面会提前告诉你「该科目下现有 N 道错题」。

### 4.3 怎么作答

1. 每题下方的输入框可以写解法（**不是必填**，但建议写，复习时能对照）
2. 做完一道就点「✓ 做对了」或「✗ 做错了」**自评**
3. 想看答案点「查看答案与解析」
4. 全部自评完，点最下方「交卷并更新掌握度」

> ⚠️ **一定要如实自评。** 这个自评直接决定你的掌握度和后续复习安排。
> 明明做错了却点「做对了」，系统就不会再安排你复习这道题。

### 4.4 没自评的题会怎样

**不计入统计**，交卷时会提示「跳过 N 题」。

### 4.5 交卷之后

会看到本次正确率和涉及知识点的掌握度变化（如「33% → 50%」）。

## 五、今日复习

主页会显示「今日复习 · N 道到期」，点「开始复习」即可。

### 5.1 为什么会「到期」

系统按遗忘曲线估算你还能记住多少。刚做过的题不会立刻出现
（要过一阵子留存率降下来才会重新进来），所以**主页显示「暂时没有到期的题」是正常的**。

### 5.2 答对之后

该题的「稳定度」会翻倍，下次到期时间大幅推后 —— 这就是间隔重复的原理。

### 5.3 答错之后

稳定度减半，很快会再次出现。**这是好事**，说明系统抓到了你的薄弱点。

## 六、备份（重要）

点主页最下方 **⚙️ 设置与备份**。

### 6.1 为什么必须备份

你的数据存在**这台设备的这个浏览器**里。以下情况会丢：

- 清理浏览器缓存 / 存储数据
- 换手机、换浏览器
- 用无痕模式（关掉窗口就没了）
- 部分手机系统的「自动清理」

### 6.2 怎么备份

点「⬇️ 导出备份（JSON）」，会下载一个 `错题通备份-YYYYMMDD-HHMM.json`。
**建议每周一次**，存到网盘或发给自己。

### 6.3 怎么恢复

点「⬆️ 从备份恢复」，选那个 json 文件。

> ⚠️ 恢复是**整体替换**，不是合并。当前的错题会被备份文件里的内容完全顶替。
> 所以恢复前如果当前数据有用，先导出一次。

### 6.4 清空

「清空全部数据」会二次确认，清空后无法撤销（除非你导出过备份）。

## 八、常见问题

**Q：会不会上传我的数据？**
A：不会。没有服务器、没有账号、没有联网请求（离线包连网络都不需要）。

**Q：支持图片吗？**
A：不支持，本版只支持文字 + LaTeX 公式。录图片请用手机相册或其它工具。

**Q：能自动判对错吗？**
A：不能，需要你自己点「做对了 / 做错了」。数学题的过程无法机器判分。

**Q：为什么掌握度不显示具体数字？**
A：样本少于 5 次时显示「数据不足」，这是统计上的诚实。多做题就会显示。

**Q：可以导出一份给老师看吗？**
A：D6 版本会加「打印」和「导出使用数据」功能。目前可以截图诊断页。

**Q：我的数据同学能看到吗？**
A：看不到。每个人的数据都在自己设备的浏览器里。

## 十、录题效率功能（2026-10 更新）

### 10.1 极速录题（默认模式）

打开「录错题」就是极速模式：**只需填来源 + 选知识点 + 选错因，就能保存**。题干可以留空。
- 「保存并继续」：保存后科目、知识点、错因都保留，只清空内容，适合连续录入。
- 上次用的科目和知识点会自动帮你选好；知识点多了用顶部搜索框过滤。
- 「保存并返回」：存完回错题本。

### 10.2 拍照 / 相册

题目图片卡在录题页**最上面**：
1. 点「📷 拍照」（调起后置相机）或「🖼️ 相册」（可一次多选），每题最多 3 张。
2. 拍完立即显示缩略图，自动压缩（长边 1280）后**只存在你手机里**。
3. 点缩略图可全屏查看，「重拍这张」「删除这张」都在里面；缩略图角上的 ✕ 直接删。
4. 只拍照、不填任何字，也能保存。
5. 换了手机或清理浏览器会丢图片——「设置 → 导出备份」时可勾选**连同图片一起备份**。
6. 个别浏览器不支持存图片（如某些隐私模式）：拍照按钮会隐藏并提示，文字录题不受影响。

### 10.3 公式工具栏

点开「展开详细填写」后，题干 / 我的答案 / 解析三个框**获得焦点时**屏幕底部会出现公式工具栏：
- 按分类（常用 / 微积分 / 线代 / 概率统计 / 集合逻辑 / 希腊）横向滑动找符号；最常用过的会排在「最近使用」。
- 点按钮插入公式，**不会收起输入法键盘**；刚插入的部分高亮成占位符 ▮，直接打字就能填上。
- 「⏭ 下一个占位」跳到下一个要填的位置；「↶ 撤销」撤销上一步插入。
- 在普通文字里点符号会自动包上 `$…$`；也有一个手动「$…$」按钮包住选中的文字。
- 保存时如果还有 ▮ 没填，会问你要不要原样保存。

### 10.4 复制为新题

错题本里每道题的「复制」按钮：把科目、知识点、错因带过去，内容清空——适合同一页的类似题。

### 10.5 不想打公式？

手机上可以用**系统自带的文字识别或其他识别工具**，把题目转成文字后直接粘贴进来；`\( \)`、`\[ \]` 写法会自动转换。粘贴的内容只存在你自己手机里，不会上传。
