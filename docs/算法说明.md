## 一、掌握度：Beta 后验均值（贝叶斯平滑）

### 1.1 问题

最朴素的做法是「答对次数 ÷ 总次数」。它有一个致命缺陷：

| 作答情况 | 朴素准确率 | 问题 |
|---|---|---|
| 答 1 题，对 1 题 | 100% | 只看了一眼就知道全懂了？ |
| 答 1 题，错 1 题 | 0% | 一次失手就被判定「完全不会」 |

这类极端值会直接毁掉后续的两件事：诊断页会给出荒唐结论，组卷权重也会被拉到边界。
样本量只有两三次时，朴素的点估计**没有任何统计意义**。

### 1.2 模型

把某知识点「每次作答答对」看作伯努利试验，正确率 $p$ 的先验取均匀分布：

$$p \sim \mathrm{Beta}(\alpha_0,\ \beta_0), \qquad \alpha_0 = \beta_0 = 1$$

每答对一次 $\alpha \mathrel{+}= 1$，每答错一次 $\beta \mathrel{+}= 1$。共答对 $a$ 次、答错 $b$ 次后：

$$p \mid \text{data} \sim \mathrm{Beta}(\alpha_0 + a,\ \beta_0 + b)$$

**掌握度取后验均值**：

$$\text{Mastery} = \frac{\alpha}{\alpha + \beta} = \frac{1 + a}{2 + a + b}$$

**95% 可信区间**取 $\mathrm{Beta}(\alpha,\beta)$ 的 2.5% 与 97.5% 分位数。

### 1.3 为什么用精确分位数而不是正态近似

正态近似是 $\bar{x} \pm 1.96\sqrt{\bar{x}(1-\bar{x})/n}$。样本很小时它会给出**负的下界**，
例如 1 次作答后算出的区间下限是负数 —— 概率不可能为负，这说明近似已经失效。

本作品用**精确的 Beta 分位数**：以二分法反解正则化不完全 Beta 函数
（连分式展开，Numerical Recipes 6.4），精度 1e-12。校验方式是用有闭式解的分布做独立对照：

- $\mathrm{Beta}(1,1)$ 是均匀分布，故 $p$ 分位数 $=p$
- $\mathrm{Beta}(2,1)$ 的密度是 $2x$，故 $\mathrm{CDF}=x^2$，$p$ 分位数 $=\sqrt{p}$

两者都与实现结果吻合到 1e-9（见 `tests/stats.test.js` 的「数学工具 · Beta 分位数」组）。

### 1.4 手算例子

**例 1：某知识点答对 3 次、答错 2 次**

$$\alpha = 1 + 3 = 4,\quad \beta = 1 + 2 = 3$$
$$\text{Mastery} = \frac{4}{4+3} = \frac{4}{7} \approx 0.5714$$
$$\text{95\% CI} = [0.2228,\ 0.8819],\quad n = 5$$

对比朴素算法 $3/5 = 60\%$：贝叶斯估计略低，因为先验把估计往 0.5 拉，
而这里恰好多答错了一次。样本量 $n=5$ 已达「数据充足」门槛。

**例 2：5 次全对**

$$\alpha = 6,\ \beta = 1,\quad \text{Mastery} = \frac{6}{7} \approx 0.8571,\quad \text{CI} = [0.5407,\ 0.9958]$$

朴素算法会给出 100%。**这是平滑最重要的作用**：全对 5 次仍然只是「很可能掌握了」，
而不是「一定掌握」。区间下界 0.54 说明真实的正确率可能只有五成多。

**例 3：只答对 1 次（对照）**

| 方法 | 结果 |
|---|---|
| 朴素准确率 | 1.0000 |
| 贝叶斯掌握度 | **0.6667** |
| 95% 可信区间 | [0.1581, 0.9874]，宽 0.8293 |
| 区间宽度 | 几乎覆盖整个 $[0,1]$ |

区间宽 0.83，这在统计上明说了一件事：**一次作答什么也证明不了**。
所以界面在 $n<5$ 时显示「数据不足」，而不是拿 67% 当结论。

**例 4：只答错 1 次**

$$\text{Mastery} = \frac{1}{3} \approx 0.3333,\quad \text{CI} = [0.0126,\ 0.8419]$$

下界 0.0126 明显大于 0 —— 精确分位数不会像正态近似那样给出负数。

### 1.5 区间宽度随样本收窄（"数据不足"的量化依据）

下表取「答对 $a$ 次、答错 $b$ 次」的几种情形（数值由 `node tests/stats.test.js` 同源实现算出）：

| 答对 / 答错 | 总样本 $n=a+b$ | 区间宽度 | 界面是否给结论 |
|---|---|---|---|
| 0 / 1 | 1 | 0.8293 | 否（数据不足） |
| 1 / 1 | 2 | 0.8114 | 否 |
| 2 / 2 | 4 | 0.7067 | 否 |
| 3 / 3 | 6 | 0.6319 | **是（首次达标）** |
| 4 / 4 | 8 | 0.5760 | 是 |
| 5 / 5 | 10 | 0.5324 | 是 |
| 10 / 10 | 20 | 0.4044 | 是 |
| 25 / 25 | 50 | 0.2681 | 是 |
| 50 / 50 | 100 | 0.1927 | 是 |
| 100 / 100 | 200 | 0.1374 | 是 |

宽度单调收窄，且样本越多收得越慢（$1/\sqrt{n}$ 量级）—— 这正是可信区间应有的行为。

**阈值 $n_{\min}=5$ 的由来**：$\mathrm{Beta}(6,1)$ 是「5 次全对」时的后验，
其 2.5% 分位数首次超过 0.5（$=0.5407$）。也就是说，到第 5 次连续答对，
我们才有 97.5% 的把握认为「真实正确率高于 50%」。在此之前，
任何结论都可能是先验与噪声的混合物。这个阈值可调（`QT.stats.CONFIG.minSamples`），
界面上也明写了当前样本量占阈值的比例（如「数据不足（2/5）」）。

**例 5：30 次全对**

$$\text{Mastery} = \frac{31}{32} \approx 0.9688,\quad \text{CI} = [0.8878,\ 0.9992]$$

仍然严格小于 1，且区间下界也升到 0.89 —— 这符合「证据越多越确定」的直觉。

### 1.6 「错题录入本身算一次答错」

这不是随意规定。它的含义是：**你把这道题记进错题本，就说明你做错了它**，
这是一次真实的、有信息量的失败观测。若不计入，用户录 10 道错题、一次都没复习时，
掌握度会停留在 0.5（先验），诊断页会说「数据不足」—— 完全违背用户的实际体验。

代码位置：`storage.addMistake()` 在写入错题的同时写入一条
`{ correct: false, kind: 'intake' }` 的事件。

**可纠错性**：`deleteMistake()` 会按 `mistakeId` 连带删除该事件。
否则误录一道题会永久压低这个知识点的掌握度，用户无法纠正。

## 二、遗忘曲线：指数遗忘与稳定度递推

### 2.1 模型

采用 Ebbinghaus 式指数遗忘：

$$R = e^{-t/S}$$

- $R$ 为记忆留存率，取值 $(0,1]$
- $t$ 为距上次作答的天数
- $S$ 为**稳定度**（单位：天），语义是「遗忘到 $1/e$ 所需的时间」

**稳定度递推规则**：

$$S \leftarrow \begin{cases} S \times 2 & \text{答对} \\ \max\left(0.5,\ S \times 0.5\right) & \text{答错} \end{cases}$$

初始 $S_0 = 1$ 天。

**复习优先级**：

$$\text{Priority} = (1 - R)\times(1 - \text{Mastery})$$

它同时惩罚「快忘了」和「没掌握」：两因子相乘，只有两者都差时才最该复习。

### 2.2 参数为什么这样取

| 参数 | 值 | 理由 |
|---|---|---|
| $S_0$ | 1 天 | 新记的错题当天 R=1，第二天 R≈0.37 —— 与「隔天再看一遍」的学习直觉一致 |
| 答对倍率 | ×2 | 指数增长对应「间隔重复」的经典结论：熟练掌握的间隔可逐次加倍 |
| 答错倍率 | ×0.5 | 答错说明记忆不牢，稳定度腰斩，很快会再次到期 |
| $S$ 下限 | 0.5 天 | 防止连续答错把 $S$ 压到 0 导致 $R\equiv 0$、该题永远黏在复习队列首位 |
| 到期阈值 | $R < 0.9$ | 低于九成留存才算「该复习了」，否则每次打开都看到刚做过的题 |

### 2.3 手算例子

**例 6：连续答对 2 次的题（$S = 1 \times 2 \times 2 = 4$），掌握度 0.3**

$$R(t) = e^{-t/4}$$

| 距上次 $t$ | $R$ | 优先级 $=(1-R)\times(1-0.3)$ |
|---|---|---|
| 0 天 | 1.0000 | 0.0000 |
| 1 天 | 0.7788 | 0.1548 |
| 2 天 | 0.6065 | 0.2754 |
| 3 天 | 0.4724 | 0.3693 |
| 4 天 | 0.3679 | 0.4425 |
| 7 天 | 0.1738 | 0.5784 |

注意 $t=S=4$ 时 $R = e^{-1} \approx 0.3679$，与稳定度的定义自洽（这点有专门的测试）。
掌握度 0.3 意味着「即使记住也做不对」，所以优先级持续上升。

**例 7：只答错过 1 次的题（$S = \max(0.5,\ 1\times0.5) = 0.5$），掌握度 $4/7 \approx 0.571$**

$$R(t) = e^{-t/0.5} = e^{-2t}$$

| 距上次 $t$ | $R$ | 优先级 |
|---|---|---|
| 0 天 | 1.0000 | 0.0000 |
| 0.5 天 | 0.3679 | 0.2709 |
| 1 天 | 0.1353 | 0.3706 |
| 2 天 | 0.0183 | 0.4207 |
| 3 天 | 0.0025 | 0.4275 |

对比例 6：同样过了 3 天，答错过的题优先级（0.4275）明显高于答对过的题（0.3693）——
模型确实做到了「错的题更早回来找你」。而且 $S$ 停在下限 0.5，$R$ 很快趋近 0
但不会变成负数或异常值，优先级收敛到 $1-\text{Mastery}$。

### 2.4 与掌握度的分工

两个模型刻意**解耦**：

- **掌握度**回答「你会不会」—— 只依赖答对/答错的次数，不依赖时间
- **遗忘曲线**回答「你现在还记得多少」—— 只依赖时间和作答次序

一个知识点可以「掌握度很高但很久没碰」（$R$ 低），也可以「昨天刚做对但整体正确率很差」。
复习优先级用乘积把两者合起来，才不会出现「只按正确率排序，导致熟练的题反复出现」的偏斜。

## 三、组卷：加权无放回抽样 + 知识点配额

### 3.1 权重定义

每道题的权重 = 其所有知识点复习优先级的**均值**，再加小常数 $\varepsilon$：

$$w_i = \frac{1}{|K_i|}\sum_{k \in K_i} \text{Priority}_k + \varepsilon, \qquad \varepsilon = 0.05$$

**为什么取均值而不是最大值**：一道题同时考「数列极限」和「微分中值定理」，
若取最大值，只要其中一章薄弱，这道题就会被当成「最薄弱的题」反复抽中，
而另一章的情况完全被掩盖。取均值更接近「这道题整体的待复习程度」。

**为什么要有 $\varepsilon$**：优先级可能恰好为 0（刚答对且掌握度高）。
若没有 $\varepsilon$，这些题的权重为 0，永远抽不到 —— 强者恒强、
早就会的题再也不出现，这与「查漏补缺」的目标相反。加 $\varepsilon$ 后它们仍保留小概率。

### 3.2 抽样算法

加权无放回抽样，每一步按剩余候选的权重归一化后随机选一个，选中即从池中移除。
实现在 `stats.weightedSample()`，随机源可注入（测试用），因此结果可复现。

### 3.3 知识点配额

任一知识点的题目数不超过：

$$\text{cap} = \left\lceil \text{总题数} \times 0.4 \right\rceil$$

**为什么需要**：如果用户 20 道错题里有 15 道都在「微分中值定理」，按纯权重抽样，
一张 10 题的卷子可能有 8 题都考这一章，练完对其它章节毫无帮助。

**配额凑不满时怎么办**：真实场景里用户往往只有两三章有题。
若死守配额，选 10 道题可能只抽得出 4 道。所以实现里做了**逐级放宽**：
配额抽不满就放宽一档再抽，最多放宽两次，仍不满则返回实际抽到的数量。
界面上会把「该科目下现有 N 道错题；实际抽出数量不会超过它」明说，
避免用户以为是 bug。

### 3.4 手算例子

**例 8：一道题挂两个知识点，优先级分别是 0.2 和 0.6**

$$w = \frac{0.2 + 0.6}{2} + 0.05 = 0.4 + 0.05 = 0.45$$

**例 9：配额的实际效果**

构造 10 道全挂在知识点 `big` 上的题（权重 5），另有 10 道各挂不同知识点（权重 0.01），
抽 10 道。配额 $\text{cap} = \lceil 10\times0.4 \rceil = 4$，
故结果中 `big` 最多出现 4 道 —— 测试用 200 次抽样验证了这一点。

**例 10：两个候选、权重 0.9 与 0.1、抽 1 道**

理论概率：

$$P(\text{hot}) = \frac{0.9 + 0.05}{(0.9+0.05)+(0.1+0.05)} = \frac{0.95}{1.1} \approx 0.8636$$

实测 2000 次抽样落在 $(0.78, 0.93)$ 区间内（测试断言）。

## 五、本作品统计方法的局限（写报告时应如实说明）

1. **先验 $\mathrm{Beta}(1,1)$ 是无信息的，不区分知识点难度**。
   「傅里叶级数」和「行列式」的先验一样。更合理的做法是按历史正确率设分级先验，
   但需要真实数据支撑，本作品没有。
2. **遗忘曲线的 $S$ 递推规则（×2 / ×0.5）是启发式，不是拟合出来的**。
   经典 SM-2 算法有更细的难度因子（EF），本作品为可解释性做了简化。
3. **「答对」由用户自评**，存在高估风险（学生容易觉得自己会了）。
   这是纯前端无后端的必然代价，在用户手册里已明确提示「如实自评」。
4. **掌握度是知识点粒度**，不区分同一知识点内不同难度的题。
5. 遗忘曲线的参数是**群体通用值**，没有按用户个人校准（需要足够多的个人数据）。

这些局限都不影响作品的核心主张（「比朴素正确率更稳、比无差别复习更有效」），
但报告里不能声称本作品能「精确预测」或「替代教师判断」。
