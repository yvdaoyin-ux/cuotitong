# 密钥轮换说明（给自己看的操作单）

> 识别功能（🔍 识别文字）依赖一把智谱 API Key。它存在于两个地方，各有各的换法。
> **任何情况下，明文密钥和口令都不进仓库、不发群、不截图。**

## 一、两把"钥匙"长什么样

| 形态 | 在哪 | 谁能看到 |
|---|---|---|
| **注入版**：`make-dist.js --ocr-key-file` 打出的单文件 html | 你发给同学的单文件里 | 拿到文件的人（技术上必然可见，混淆不算安全） |
| **口令解锁版**：`js/ocr-vault.js` 密文包（线上/仓库） | 公开仓库，任何人可见密文 | 只有知道口令的人能解出密钥 |

两种形态**可以并存**：线上版走口令解锁，单文件版直接内置。

## 二、比赛结束后必须做（11 月 4 日之后）

到智谱控制台（open.bigmodel.cn → API 密钥）**删除或停用**这把专用密钥。
- 同学手里的单文件：识别按钮会报「密钥无效（code 1000）」，**其余功能全部正常**；
- 线上口令解锁版：解出的旧密钥同步失效，同样报「密钥无效」；
- 这是一把专用赠送账号的 key，不充值，没有任何后续扣费风险。

## 三、发现额度异常消耗时（怀疑 key 外流）

1. **先止损**：智谱控制台把旧密钥**停用/删除**（立刻生效，旧文件全失效）；
2. 控制台**新建一把密钥**，存进本地一个临时文件（比如桌面 `key.txt`）；
3. 想换注入版单文件：
   ```
   node build/make-dist.js --ocr-key-file "C:\Users\fa'r\Desktop\key.txt"
   ```
   把新打出的 `dist\错题通-单文件.html` 重新发给同学；发完删掉 key.txt；
4. 想换线上解锁版：
   ```
   node build/encrypt-key.js "C:\Users\fa'r\Desktop\key.txt"
   ```
   （会提示输入口令，不回显）→ 生成新的 `js/ocr-vault.js` → `git add js/ocr-vault.js` → 提交推送。
   **口令也要换新的**，并私下告知同学。
5. 删掉 key.txt。

## 四、口令解锁版的三条限制（如实，别忽略）

1. **口令至少 16 位且随机**（建议密码管理器生成）。密文是公开的，可以被离线暴力猜——**口令强度是唯一防线**，弱口令等于把密钥挂在网上；
2. 知道口令的人可以自己解出密钥——信任模型与「发带密钥的单文件」相同，只是挡住了网页上素不相识的陌生人；
3. 换口令 = 重跑 `encrypt-key.js`（新口令会生成完全不同的密文包，盐和 IV 每次随机）。

## 五、每日护栏（已内置，不用你管）

每台设备每天最多 **30 次成功识别**（失败不计数），写死在应用里；识别失败不影响录题——照片本来就存好了。
