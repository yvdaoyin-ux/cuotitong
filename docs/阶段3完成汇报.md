## 一、做了什么（对照任务书第 3.1–3.5 节）

### 3.1 采集

- 两个按钮：`拍照`（`<input type="file" accept="image/*" capture="environment">`）与`相册`（无 capture）。**每题最多 3 张**。
- 压缩：长边 ≤1280px，JPEG 质量 0.72 起步，>200KB 逐档降到 0.5（阶梯 [0.72, 0.61, 0.5]）。`createImageBitmap(file, {imageOrientation:'from-image'})` 优先，不支持时退化 `<img>` + canvas（白底填充防透明变黑）。
- 「算目标尺寸/质量阶梯/体积判断」写成纯函数（`js/image-pipeline.js`），Node 可测。

### 3.2 存储

- IndexedDB 库 `qt-images`、store `images`：`{ id, qid, blob, w, h, size, createdAt }`（比任务书多存一个 `size` 字节字段，供占用统计）。**存 Blob 不存 base64，不碰 localStorage**。
- 错题记录只存 `imageIds: string[]`（schema v3 字段，阶段 1 已就位）。
- 删除错题即时连带删图；应用启动时孤儿清理兜底（只走 qid 索引的键游标，不把 blob 载入内存）。
- `navigator.storage.persist()` 已申请（失败静默）。设置页显示图片占用（`navigator.storage.estimate`），>100MB 红字提示。
- `ImageStore` 接口：内存实现（Node 测试）+ IndexedDB 实现，**全部方法返回 Promise**，同一契约；IndexedDB 打不开时 resolve `null`，由 UI 降级。

### 3.3 展示

- 列表：每题首图缩略图（96px）；组卷作答页：题干空时显示来源行 + 图片；打印页：图片 `break-inside: avoid`、`max-width:100%`。
- 全屏查看器（`js/image-view.js`）：黑底、双指捏合缩放（CSS `touch-action:none` + JS transform）、双击 1x/2x、多图左右切换。不引库。
- objectURL 统一登记，页面 dispose 时 `revokeAll()`。

### 3.4 备份与导出

- 备份 JSON 默认**不含图片**；设置页新增「连同图片一起备份」勾选，含图时逐张转 base64 附在 `images` 数组，**超过 20MB 先弹确认**。导入自动识别两种格式（先摘出 `images` 再走 `importJson`，不让图片混进业务数据）。
- **匿名使用数据导出不含图片**：新增 3 项隐私测试（匿名 JSON 搜不到 imageId/base64/blob/题目文本；事件 payload 白名单外的 `imageData` 键被丢弃；CSV 无图）。

### 3.5 降级

- IndexedDB 打不开（隐私模式 / `file://` 受限 / 超时 4s / onblocked）：打开拍照按钮保持禁用 → 确认不可用后隐藏按钮区，显示「当前环境不支持保存图片，请用文字或来源录题」。**不崩、不影响其他功能**。
- 测试：模拟 `indexedDB.open` 抛异常 / onerror / onblocked 三种死法 + null factory，全部 resolve null 不 reject。

### 录题页交互（AGENTS.md 阶段 3 约束）

- 极速模式下拍照卡是**第一个卡片**（首选路径）；拍完立即原位显示缩略图；点缩略图进全屏查看器，可「重拍这张」「删除这张」；缩略图角上另有 ✕ 快捷删除。
- 「保存并继续」：照片清空、其余保留（与文本一致），toast「已保存第 N 题」。
- 只拍照不填字可保存（imageIds 算「有内容」，v3 校验）。

## 四、本次踩到的坑（已写入 PROJECT_STATE）

1. **`openKeyCursor` 在对象存储上返回主键，在索引上才返回索引键**：第一版 `listQidPairs` 直接在 store 上开游标，qid 全是 undefined——孤儿清理会把所有图误判为孤儿。开发中自查发现，改为走 `qid` 索引（key=qid、primaryKey=id）。
2. **待提交图片忘记建 objectURL**：初版 `url:null`，缩略图永远显示「…」。合成图实测当场暴露。
3. **`reset()` 把 store/stripEl 一并置空**：「保存并继续」后照片卡会失灵。拆成 `reset()`（清池子，页面继续用）与 `dispose()`（离开页面）。
4. **Windows 无头 Edge 两个坑**：`--dump-dom` 的 stdout 被丢弃（GUI 子系统），必须走 CDP 读结果；`--headless`（旧模式）会打开同步欢迎页丢掉命令行 URL，**必须 `--headless=new`**（此坑与 PROJECT_STATE 里旧条目「必须加 --user-data-dir」叠加使用）。
5. **测试框架 group() 忘了调用回调**：队列里只有组名没有用例，「0 项 0 失败」假绿。教训：测试数必须与预期对账。
